## ✨ Features

*   **No Login Required**: Your text is saved in the URL using a secure hash. Write instantly and share anywhere (Reddit, Discord, etc.) with one click.
*   **Ambient Soundscapes**: Built-in background sounds (Rain, Fire, Forest, etc.) to match your writing mood.
*   **Themes**: Beautiful "Paper", "Dark", "Sepia", and "Forest" themes to reduce eye strain.
*   **Focus Goals**: Set a daily word count goal.
*   **Sai Cat Companion**: A tiny writing companion that watches your progress, keeps you motivated, and helps you stay focused until your goal is done.
*   **Distraction-Free**: Minimalist interface that puts your words front and center.

## 🚀 About

Midgen Focus Editor is built for simplicity and speed. It's always free and open source.

**Link**: [https://midgenlabs.com/focus-editor](https://midgenlabs.com/focus-editor)

## 🛠️ Tech Stack

*   **Framework**: [React Native](https://reactnative.dev/) / [Expo](https://expo.dev/)
*   **Web Support**: React Native Web
*   **Desktop Wrapper**: [Electron](https://www.electronjs.org/)
*   **State Management**: URL-based state (LZ-String compression) + Local Storage persistence.
